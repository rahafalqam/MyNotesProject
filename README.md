# My Notes Project

An Android note-taking application developed for the ENCS5150 – Advanced Computer Systems Engineering Laboratory course.

## Features
- User Sign Up, Sign In, and Logout
- Remember Me option
- Add, view, edit, and delete notes
- Mark notes as favorites
- View all notes and favorite notes
- Sort notes by creation date or alphabetically
- Search notes by title or content
- Edit user profile information
- Send notes by email
- Categorize notes using tags or labels
- Save sorting preferences
- Use fragments and animations

## Project Files
- `MyNotesProjectt.zip` — Android Studio project files.
- `app-debug.apk` — Debug APK for installing and testing the application.

## Requirements
- Android Studio
- Android device or emulator

## How to Run
1. Download or clone this repository.
2. Extract `MyNotesProjectt.zip`.
3. Open Android Studio.
4. Select **Open** and choose the extracted project folder.
5. Wait for Gradle Sync to finish.
6. Run the application on an Android device or emulator.

## APK Installation
1. Download `app-debug.apk`.
2. Open the APK on your Android device.
3. Allow installation if prompted.
4. Install and launch the application.
